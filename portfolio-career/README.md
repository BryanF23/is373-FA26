# 1. Portfolio + career research

## Purpose and intended reader

I want to build a portfolio that shows the kind of work I can do in human-computer interaction, XR, and applied AI. The main reader is a recruiter or hiring manager looking for someone who can work with users, understand a problem, build or prototype a solution, and explain technical decisions.

My current career direction is **Forward Deployed Engineer (FDE)**, with **Applied AI / AI Solutions Engineer** as a related direction to keep exploring.

### Career direction comparison

| Direction | What the work involves | Why I am considering it |
|---|---|---|
| Forward Deployed Engineer | Work closely with users or customers, understand real problems, build and integrate technical solutions, and help get them working in real environments. | This combines technical work with communication, problem-solving, and understanding how people use technology. |
| Applied AI / AI Solutions Engineer | Build AI-powered applications, connect models to data and software, test outputs, and help users apply AI to specific tasks. | This connects to my interest in AI, RAG systems, and building useful applications. |

**Current decision:** Focus the portfolio toward FDE roles while showing applied AI and XR projects as evidence of technical range. This is an initial direction, not a final career decision.

## Skills and evidence I can show

| Skill or responsibility | Evidence I can develop into a portfolio example |
|---|---|
| Understanding user needs and interaction | HCI coursework and design assignments |
| Explaining and demonstrating technical tools | NJIT XR Lab work, including helping students and faculty use VR applications |
| Troubleshooting hardware and software | Meta Quest 3 setup, app updates, controller checks, casting, and headset troubleshooting |
| Researching technical products | XR platform and application research for the lab |
| Building and integrating software | Self-hosted Flask application using Docker, PostgreSQL, Traefik, and DigitalOcean |
| Writing technical documentation | Knowledge-base articles and learning resources for XR applications |
| Prototyping and development | Unity projects and other coursework using programming and 3D tools |

I need to turn these into case studies with a clear problem, my role, the process, the result, and evidence. I should be accurate about what each project demonstrates and not claim results that I did not test or document.

## Planned portfolio pages

1. **Home:** Short introduction, target role, selected projects, and links to contact or professional profiles.
2. **About:** HCI background, interests, and tools I use.
3. **Projects:** Case studies for XR Lab work, the self-hosted application, and selected HCI or development projects.
4. **Technical skills:** A focused list of tools with examples of how I used them.
5. **Resume / contact:** A current resume and professional contact links.

## Layout comparison and decision

| Layout | Benefits | Trade-offs |
|---|---|---|
| Single long scrolling page | Simple to navigate and gives a quick overview. | Detailed projects can make the page too long. |
| Homepage with separate project pages | Keeps the homepage easy to scan and gives each project room for process and evidence. | Requires more pages to maintain. |

**Current decision:** Use a simple homepage with project cards that link to separate case-study pages. This should make it easier for a recruiter to find relevant work quickly.
